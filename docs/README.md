#Документация проэкта geometric_lib

## Общее описание решения 

Проэкт 'geometric_lib' предназначен для вычисления площади и периметров гометрических фигур:

- круга;
- квадрата;
- треугольника.

Для каждой фигуры реализованны функции:

- вычисление площади;
- вычисление периметра.

## Математические формулы 

### Площадь 

- Круг: 'S = pi*R*R'
- Квадрат: 'S = a*a'
- Треугольник: 'S = ah / 2'

### Периметр 

- Круг: 'P = 2piR'
- Квадрат: 'P = 4a' 
- Треугольник: 'P = a + b +c'

## Функции 

### circle.py

#### area(r)

Вычисляет площадь круга. 

#### Пример вывода:

area(5)

#### perimeter(r)

Вычисляет длину окружности.

#### Пример вызова:

perimeter(5)

### squere.py

#### area(a)

Вычисляет площадь квадрата.

#### perimeter(a)

Вычисляет периметр квадрата.

#### Пример вызова

perimetr(5)

### triangle.py 

#### area(a, h)

Вычисляет площадь треугольника.

#### Пример вызова

area(5, 10)

#### perimeter(a, b, c)

Вычисляет периметр треугольника.

#### Пример вызова

area(3, 4, 5)
